# Aurora v0.1.13.2

本次更新新增了**同一版本下多个文件的选择功能**，解决了部分 Mod 的同一版本提供多个安装包时，Aurora 无法让用户自主选择的问题。

## 在线 Mod 支持选择同一版本下的多个文件

部分资源站允许一个版本同时上传多个文件。例如：

- **ChartRendering 1.1.1**
  - 基础包（约 0.3 MB）：首次使用时自动下载 FFmpeg。
  - 完整包（约 84 MB）：内置 FFmpeg。

此前，Aurora 只会自动选择 UnityModManager 文件，或直接使用文件列表中的第一个文件。当一个版本同时提供基础包和完整包时，用户无法自行选择需要的安装包。

现在，Aurora 已支持在同一版本下选择不同文件：

- **详情页新增文件选择器**：在「版本」下方新增「文件」下拉框，可查看并选择当前版本提供的文件。
- **切换版本时同步刷新**：选择不同版本后，文件列表也会随之更新。
- **多个文件由用户自行选择**：默认仍优先选择 UnityModManager 文件，例如 AETC 1.1.1 的基础包和完整包。
- **兼容单文件版本**：只有一个文件时，仍会显示文件名和大小，但选择器不可操作。
- **兼容第三方来源**：TUF、modlist 等没有提供文件列表的来源会自动隐藏文件选择器，不影响原有使用体验。

从「已安装」页面更新 Mod 时，同样支持选择目标版本的安装文件。如果目标版本包含多个文件，Aurora 会弹出选择窗口供用户确认。

此外，Aurora 会记住用户上次选择的文件变体：通过**去掉版本号后的文件名**进行匹配。当该 Mod 发布新版本时，会自动预选名称相同的文件，不需要每次更新都重新选择。

## 缓存逻辑调整

资源站安装缓存现在改为使用 `file.Id` 区分文件。

此前，基础包和完整包可能具有相同的版本号，导致它们命中同一份缓存。调整后，即使版本号相同，不同文件也会使用各自对应的缓存，避免安装时错误复用文件。

## 升级方式

**建议所有用户更新。**

使用 v0.1.6 或更高版本的用户，可以直接在软件内点击「立即更新」。

也可以退出软件后手动升级：

| 版本 | 操作 |
| --- | --- |
| 安装版 | 运行 `Aurora-Setup-0.1.13.2.exe`，覆盖安装 |
| 绿色版 | 将 ZIP 压缩包解压并覆盖到原来的程序目录 |

> v0.1.5 及更早版本自带的自动更新功能存在问题，请手动下载安装包覆盖安装，或解压 ZIP 覆盖原程序目录。

升级不会影响原有设置、收藏和日志。建议升级前备份游戏目录中的 `Mods` 文件夹。
