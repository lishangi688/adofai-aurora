# Aurora v0.1.13.5

本次更新将内置 UnityModManager（UMM）内核升级至 **0.33.4**，并新增内核版本检测与更新提示，方便用户及时更新加载器内核。

此外，重新设计了「选择要更新的文件」窗口，使其在深色和浅色主题下都能与 Aurora 的其他界面保持一致。

## 内置 UMM 内核升级至 0.33.4

内置加载器内核同步跟进上游 UnityModManager 更新：

| 组件 | 原版本 | 新版本 |
| --- | --- | --- |
| UnityModManager | 0.33.3 | **0.33.4** |
| Harmony | 2.3.6 | **2.4.3** |

注入组件 `winhttp_x64.dll`、`winhttp_x86.dll`、`dnlib.dll` 和 `UnityModManager.xml` 均与上一版本保持一致，本次未作改动。

### 新增内核更新提示

Aurora 启动时会自动检查内置 UMM 内核与游戏中已部署的内核版本是否一致。此过程仅读取本地文件，不会联网检查。

检测到内置版本较新时，会在主界面顶部显示提示条，例如：

> UMM 内核有新版本 v0.33.4（当前 v0.33.3）

用户可以通过以下方式处理：

- **去更新**：跳转至「UMM 环境」页面，在该页面点击「立即更新内核」即可完成升级。
- **忽略此版本**：暂时不更新，并在后续内核版本发布前停止提示。
- **直接从 UMM 环境页面更新**：「UMM 环境」页面也会显示相同的更新提示，无需再通过「安装 / 修复加载器」选项进入更新流程。

### 新增内核回滚能力

更新内核前，Aurora 会自动备份当前已部署的内核。

如果升级后发现某些旧版 Mod 出现异常，可以在「UMM 环境」页面点击「回滚内核」，恢复到升级前的版本。

> 首次安装 UMM，或此前从未部署过加载器的用户，无需额外操作，直接使用「安装 / 修复加载器」即可。

## 重新设计「选择要更新的文件」窗口

在「已安装」页面更新提供多个安装文件的 Mod 时（例如 AETC 的基础包和完整包），Aurora 会弹出文件选择窗口，供用户选择需要更新的文件。

此前，该窗口使用系统默认列表样式，与 Aurora 的其他界面存在一定的视觉差异。本次对窗口进行了重新设计：

- **卡片式文件列表**：改用卡片布局，与在线 Mod 和已安装 Mod 的列表样式保持一致。
- **交互状态优化**：鼠标悬停时高亮显示，选中的文件则通过强调色描边和勾选标记进行区分。
- **标题区域调整**：将 Mod 名称与目标更新版本（`更新到 x.y.z`）分开显示，避免名称较长时挤占标题区域。
- **列表滚动与窗口自适应**：文件较多时，仅列表区域滚动；窗口高度则根据内容自动调整。
- **保留文件选择记录**：此前记住的文件变体选择继续生效，符合条件的同名文件会在下次更新时自动预选。

## 升级方式

**建议所有用户更新。**

使用 v0.1.6 或更高版本的用户，可以直接在软件内点击「立即更新」。

也可以退出软件后手动升级：

| 版本 | 操作 |
| --- | --- |
| 安装版 | 运行 `Aurora-Setup-0.1.13.5.exe`，覆盖安装 |
| 绿色版 | 将 ZIP 压缩包解压并覆盖到原来的程序目录 |

> v0.1.5 及更早版本自带的自动更新功能存在问题，请手动下载安装包覆盖安装，或解压 ZIP 覆盖原程序目录。

升级不会影响原有设置、收藏和日志。建议升级前备份游戏目录中的 `Mods` 文件夹。
