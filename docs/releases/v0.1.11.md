# Aurora v0.1.11

本次更新新增了 Mod 来源管理功能，可以按需关闭不使用的来源；优化了更新检查机制，不再受 GitHub API 限流影响。同时，对更新检查流程进行了多项优化，实测耗时降低至原来的约三分之一。此外，内置 UnityModManager 内核升级至 0.33.3。

## 可以关闭不需要的来源

设置中新增「来源 → 启用的来源」，可以根据需要启用或关闭各个 Mod 来源：

- 支持单独开关 ADOFAI Tools、modrift、TUF、modlist，以及「自定义站点」（配置后显示）；
- 已关闭的来源不会出现在「在线 Mod」的来源列表中；
- 更新检查（包括启动时的自动检查）会自动跳过已关闭的来源；
- 关闭默认站点时，也会同时跳过该站点的 Mod 列表及 Aurora 自身的站点更新通道；
- 至少需要保留一个来源。当只剩一个来源时，无法继续关闭，系统会自动恢复勾选并给出提示。

> 如果某些来源在你的网络环境下响应较慢（例如 TUF），可以尝试关闭它们，以缩短启动时的检查时间。

## GitHub 也可以单独关闭

GitHub 本身并不是 Mod 内容来源，不会出现在「在线 Mod」的来源列表中，但它在更新检查过程中也会占用一定时间。

现在，「更新检查」中的「同时查询 GitHub」选项已移至「来源 → 启用的来源」，并更名为「GitHub（仅检查更新）」。

这样一来，所有来源的开关都集中在同一个位置，管理起来更加方便。

## 不再出现一片「检查失败」

此前，更新检查需要逐个通过 GitHub API 查询 Mod 的最新版本。GitHub 未登录状态下的开放接口每小时只有 60 次 API 额度，且按 IP 计算。安装的 Mod 较多时，检查几次就可能耗尽额度，导致后续所有依赖 GitHub 的 Mod 均显示「检查失败」。

现在改为通过读取 GitHub 发布页的跳转地址获取最新版本号，**正常检查不再消耗 API 额度**：

- 一次完整检查（12 个 Mod）消耗 **0 次** API 额度，全部检查成功；
- 只有确实发现新版本、需要获取下载地址时，才会额外请求一次 API；
- 如果这次请求恰好遇到限流，仍会保留「发现新版本」的结果，并提示前往发布页手动下载，不再直接判定为检查失败；
- 如果发布页无法访问，则自动回退到原有的 API 查询方式。

## 更新检查更快

对更新检查流程进行了三项优化：

- **Mod 并发检查**：最多同时检查 6 个 Mod，不再逐个等待；
- **来源目录并发获取**：TUF、modlist、modrift 的目录数据并发拉取，不再依次等待；
- **来源对象复用**：复用已有的网络客户端，减少重复创建连接和握手带来的开销。

实测数据（冷缓存、全部来源开启、12 个已安装 Mod）：

| 版本 | 检查耗时 |
| --- | --- |
| v0.1.10 | 16.2 秒 |
| v0.1.11 | **6.1 秒** |

整体检查耗时降低约 **62%**，缩短至原来的约 38%。

其中，第三方来源目录的获取耗时也从 7.6 秒降低至 3.8 秒。

实际耗时会受到网络环境、启用的来源及已安装 Mod 数量等因素影响。

## 切页不再「顿一下」

此前，「已安装」页面在显示时会同步重建 Mod 列表，耗时约 100 毫秒，恰好发生在页面切换动画开始时，因此可能出现短暂卡顿。

现在调整为等待页面切换动画结束后再重建列表，切换至「已安装」页面时不再出现这一停顿。

更新检查结束后的列表刷新也进行了相同调整。

## 内置 UnityModManager 更新

内置 UnityModManager 内核从 0.33.2 升级至 **0.33.3**。

在「安装 / 修复加载器」中选择内置内核时，将使用这一版本。如果游戏中部署的仍是旧版本，「UMM 环境」页面会提示更新。

## 诊断日志

调试日志新增了更详细的更新检查记录，包括每个 Mod 的检查结果、耗时，以及各个来源获取到的数据数量。

示例：

```text
[check] AccurateJudgementBar 用时 1667ms · 已是最新
[check] 源 tuf 取到 160 条（1967ms）
```

反馈问题时附上日志，可以更方便地定位具体是哪个 Mod 或来源出现了延迟、失败等问题。

## 升级方式

使用 v0.1.6 或更高版本的用户，可以直接在软件内点击「立即更新」。也可以退出软件后手动升级：

| 版本 | 操作 |
| --- | --- |
| 安装版 | 运行 `Aurora-Setup-0.1.11.exe`，覆盖安装 |
| 绿色版 | 将 ZIP 压缩包解压并覆盖到原来的程序目录 |

> v0.1.5 及更早版本自带的自动更新功能存在问题，请手动下载安装包覆盖安装，或解压 ZIP 覆盖原程序目录。

原有设置、收藏和日志均会保留。**建议所有用户更新至此版本。** 升级前建议备份游戏目录中的 `Mods` 文件夹。
