# Aurora v0.1.12

本次更新把 ADOFAI Tools 做成了开箱即用：Aurora 内置了一个专用公共 key，第一次启动就能直接浏览和下载 Mod，不需要自己去站点申请 key。同时重做了首次使用向导，并把默认来源收敛到最稳定的 ADOFAI Tools。

## 不用再自己填 API key

Aurora 现在内置了一个 ADOFAI Tools 专用公共 key：

- 第一次启动就能直接浏览、搜索、下载，不需要登录，也不需要去站点个人中心创建 key；
- 如果之前已经填过自己的 key，仍然优先使用自己的；
- 内置 key 只会发给 ADOFAI Tools，不会随自定义站点一起发送；
- 这个 key 随开源客户端公开，属于公共凭据，不是秘密；如果被滥用，可以在站点后台随时撤销或更换。

> 内置 key 是所有 Aurora 用户共用的，站点如果限流，可能会出现短暂的失败提示。这时在「设置」里填一个自己的 key 即可，功能和速度都不受影响。

## 首次使用向导重做

向导步骤调整为更符合实际使用顺序：

1. **游戏目录**：自动识别或手动选择；
2. **UMM 加载器**：可以直接查询 ADOFAI Tools 上的内核版本，和 Aurora 内置内核比较后推荐较新的那个；也可以继续用内置内核或导入本地 zip；
3. **资源站**：选择要启用的来源，默认只勾选 ADOFAI Tools。

几点细节：

- 由于内置了 key，第二步现在可以直接从资源站获取内核，不再需要先配置 key；
- 第三步默认只启用 ADOFAI Tools —— 它最稳定、访问也快；modrift、TUF、modlist 可以随时勾上；
- 至少要保留一个来源；如果全程没有修改，点「完成」时也会自动只保留 ADOFAI Tools；
- 之后可以在「设置 → 启用的来源」里随时调整。

## 内置 key 失效或限流时

- 401：提示内置 key 可能已被撤销，并引导到「设置」填写自己的 key；
- 403：提示内置 key 被站点拒绝，同样可以换自己的 key；
- 429：提示请求过于频繁，稍后再试或换自己的 key。

这些提示不会阻断本地功能：即使不填 key，已安装的 Mod、加载器管理和本地 zip 安装仍然可用。

## 升级方式

使用 v0.1.6 或更高版本的用户，可以直接在软件内点击「立即更新」。也可以退出软件后手动升级：

| 版本 | 操作 |
| --- | --- |
| 安装版 | 运行 `Aurora-Setup-0.1.12.exe`，覆盖安装 |
| 绿色版 | 将 ZIP 压缩包解压并覆盖到原来的程序目录 |

> v0.1.5 及更早版本自带的自动更新功能存在问题，请手动下载安装包覆盖安装，或解压 ZIP 覆盖原程序目录。

原有设置、收藏和日志均会保留。升级前建议备份游戏目录中的 `Mods` 文件夹。
