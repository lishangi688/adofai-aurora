# Aurora v0.1.12

本次更新重点优化了首次使用体验。Aurora 现在内置 ADOFAI Tools 专用公共 API Key，首次启动即可直接浏览、搜索和下载 Mod，无需自行申请或配置 Key。同时，重新设计了首次使用向导，调整默认来源配置，进一步降低软件的使用门槛。

## 不用再自己申请 API Key

此前，首次使用 Aurora 时，需要先前往 ADOFAI Tools 个人中心申请 API Key，才能正常使用相关资源站功能。

现在，Aurora 内置了一个专用于 ADOFAI Tools 的公共 API Key：

- 首次启动即可直接浏览、搜索和下载 Mod，无需登录或自行创建 Key；
- 如果此前已经配置了自己的 Key，仍然优先使用用户自行配置的 Key；
- 内置 Key 仅用于 ADOFAI Tools，不会随请求发送到自定义站点；
- 内置 Key 随开源客户端公开，属于公共凭据，并非保密信息。如果遭到滥用，可以通过站点后台随时撤销或更换。

> 内置 Key 由所有 Aurora 用户共用。如果站点对公共 Key 实施限流，可能会出现短暂的请求失败。遇到这种情况，可以在「设置」中填写自己的 API Key。

## 首次使用向导重做

重新调整了首次使用向导的步骤和内容，使配置流程更加符合实际使用顺序：

1. **游戏目录**：自动识别 ADOFAI 游戏目录，也可以手动选择。
2. **UMM 加载器**：直接查询 ADOFAI Tools 提供的内核版本，并与 Aurora 内置内核进行比较，推荐较新的版本；也可以选择继续使用内置内核或导入本地 ZIP 文件。
3. **资源站**：选择需要启用的 Mod 来源，默认仅启用 ADOFAI Tools。

其他调整：

- 由于现在内置了 API Key，配置 UMM 加载器时即可直接从资源站获取内核，无需提前配置 Key；
- 默认仅启用 ADOFAI Tools。该来源稳定性较好，访问速度也较快；modrift、TUF 和 modlist 均可根据需要手动启用；
- 至少需要保留一个 Mod 来源。如果没有手动调整来源配置，点击「完成」时会自动仅保留 ADOFAI Tools；
- 完成向导后，仍然可以在「设置 → 启用的来源」中随时调整来源配置。

## 内置 Key 失效或限流时的处理

针对内置公共 Key 可能遇到的异常情况，增加了相应的提示和处理引导：

- **401**：提示内置 Key 可能已被撤销，并引导用户前往「设置」填写自己的 Key；
- **403**：提示内置 Key 被站点拒绝，同样支持切换为自己的 Key；
- **429**：提示请求过于频繁，建议稍后重试或更换自己的 Key。

这些异常不会影响 Aurora 的本地功能。即使没有配置可用的 API Key，仍然可以正常使用已安装 Mod 管理、加载器管理以及本地 ZIP 安装等功能。

## 升级方式

使用 v0.1.6 或更高版本的用户，可以直接在软件内点击「立即更新」。也可以退出软件后手动升级：

| 版本 | 操作 |
| --- | --- |
| 安装版 | 运行 `Aurora-Setup-0.1.12.exe`，覆盖安装 |
| 绿色版 | 将 ZIP 压缩包解压并覆盖到原来的程序目录 |

> v0.1.5 及更早版本自带的自动更新功能存在问题，请手动下载安装包覆盖安装，或解压 ZIP 覆盖原程序目录。

原有设置、收藏和日志均会保留。**建议所有用户更新至此版本。** 升级前建议备份游戏目录中的 `Mods` 文件夹。
