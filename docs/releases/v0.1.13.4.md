# Aurora v0.1.13.4

本次更新让 Aurora 的自动更新可以根据当前安装形态选择资源站上的不同文件，避免安装版和绿色版都去下载体积更大的合并包。

## 自动更新按安装形态选择文件

ADOFAI Tools 的工具版本现在可以同时提供多个文件：

- `Aurora-0.1.13.4-all.zip`：合并包，兼容旧客户端；
- `Aurora-Setup-0.1.13.4.exe`：安装版；
- `Aurora-v0.1.13.4-win-x64.zip`：绿色版。

此前自动更新只会读取 `file`（合并包），所以安装版和绿色版都会下载约 112 MB 的 `all.zip`。

现在：

- **安装版**更新时优先下载 `Aurora-Setup-*.exe`，找不到时回退到合并包；
- **绿色版**更新时优先下载普通绿色版 zip，找不到时回退到合并包；
- 旧版客户端仍可读取 `file` 字段，更新不受影响；
- 文件名会保持稳定，Aurora 按文件名区分安装版 / 绿色版（资源站目前没有文件角色字段）。

> 从 0.1.13.4 起，安装版和绿色版的自动更新会分别下载对应文件，合并包只作为兼容和回退。

## 其他

- 0.1.13.3 加入的文件 SHA256 校验继续生效；
- 普通 Mod 的同版本多文件选择保持可用。

## 升级方式

**建议所有用户更新。**

使用 v0.1.6 或更高版本的用户，可以直接在软件内点击「立即更新」。

也可以退出软件后手动升级：

| 版本 | 操作 |
| --- | --- |
| 安装版 | 运行 `Aurora-Setup-0.1.13.4.exe`，覆盖安装 |
| 绿色版 | 将 ZIP 压缩包解压并覆盖到原来的程序目录 |

> v0.1.5 及更早版本自带的自动更新功能存在问题，请手动下载安装包覆盖安装，或解压 ZIP 覆盖原程序目录。

升级不会影响原有设置、收藏和日志。建议升级前备份游戏目录中的 `Mods` 文件夹。
