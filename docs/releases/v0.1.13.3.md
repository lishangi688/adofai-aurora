# Aurora v0.1.13.3

本次更新接入了 ADOFAI Tools 新增的文件哈希字段，为 Mod 安装、自动更新和 UMM 内核下载增加 SHA256 校验，进一步提升下载与安装过程的可靠性。

同时，Aurora 现已兼容 ADOFAI Tools 新版接口的多文件结构，为后续支持工具类资源的多文件下载做好准备。

## 下载文件 SHA256 校验

ADOFAI Tools 现在会在文件元数据中提供 `sha256` 字段，Aurora 已接入这一校验机制，覆盖以下操作：

- **在线安装 Mod**：下载完成后核对文件 SHA256。
- **更新已安装 Mod**：从「已安装」页面发起更新时，同样会进行校验。
- **从收藏页安装**：通过收藏页面安装 Mod 时，也会核对文件哈希。
- **安装缓存校验**：使用本地安装缓存前，先检查文件哈希；如果校验不通过，会丢弃旧缓存并重新下载。
- **Aurora 自身更新**：下载更新文件后，先核对 ADOFAI Tools 提供的 SHA256；GitHub Release 中的 `SHA256SUMS.txt` 仍作为独立的校验来源。
- **UMM 内核下载**：下载内核时也会使用资源站提供的哈希进行校验。

如果文件哈希不一致，Aurora 会中止安装或更新，并提示文件可能已被篡改或下载不完整，避免继续使用未经验证的文件。

**兼容性说明：**

- 如果资源站未提供文件哈希（例如旧文件），Mod 安装仍会按照原有流程继续，不会因此无法安装。
- 如果 Aurora 自更新时无法获取 ADOFAI Tools 提供的哈希，同时也无法获取 GitHub Release 的校验文件，则会在更新结果中提示本次未进行哈希校验。

## 兼容 ADOFAI Tools 新版多文件结构

ADOFAI Tools 新版接口为工具版本增加了 `files[]` 字段，同时保留原有的 `file` 字段。Aurora 现已兼容新旧两种数据结构：

- **兼容旧版接口**：仍可正常读取原有的 `file` 字段。
- **兼容新版接口**：支持读取新增的 `files[]` 字段。
- **保留主要文件选择逻辑**：目前接口尚未提供文件角色信息（例如安装版、绿色版），因此 Aurora 仍以主要文件为准，不会擅自选择其他文件。

本次仅完成了新版接口的数据结构兼容，尚未开放工具类资源的多文件自主选择。后续如果资源站提供更完整的文件信息，Aurora 可以在此基础上进一步支持。

普通 Mod 的同版本多文件选择功能已在 v0.1.13.2 中加入。

## 升级方式

**建议所有用户更新。**

使用 v0.1.6 或更高版本的用户，可以直接在软件内点击「立即更新」。

也可以退出软件后手动升级：

| 版本 | 操作 |
| --- | --- |
| 安装版 | 运行 `Aurora-Setup-0.1.13.3.exe`，覆盖安装 |
| 绿色版 | 将 ZIP 压缩包解压并覆盖到原来的程序目录 |

> v0.1.5 及更早版本自带的自动更新功能存在问题，请手动下载安装包覆盖安装，或解压 ZIP 覆盖原程序目录。

升级不会影响原有设置、收藏和日志。建议升级前备份游戏目录中的 `Mods` 文件夹。
