# Aurora v0.1.13

本次更新重点提升了 Aurora 的**安装可靠性、数据安全性和运行稳定性**。

重构了 Mod 覆盖安装流程，修复了更新中断可能导致旧版本丢失的问题；统一了游戏目录路径处理方式，增强了加载器、内核及自动更新的安全校验。此外，还补充了自动化回归测试和 CI 工作流，进一步提高后续版本的维护质量。

## 安装与更新可靠性改进

### 更安全的 Mod 覆盖安装机制

此前，覆盖安装采用逐个文件复制的方式。如果操作过程中程序被强制关闭、断电，或用户确认退出，可能导致 Mod 文件不完整，甚至使原有版本备份丢失。

现在，Aurora 重构了整个安装流程：

- **暂存安装：** 先在临时目录中完成旧版本内容合并与新版本文件覆盖。
- **整体替换：** 确认所有文件准备完毕后，再通过一次目录重命名完成替换。
- **中断恢复：** 如果安装过程中发生意外中断，原有版本会得到保留，并在下次启动时自动恢复。
- **旧版本修复：** 针对 v0.1.10～v0.1.12.2 遗留的半完整安装目录，增加了备份恢复机制。原目录会保留为 `.aurora-recovered-*`，并在「已安装」页面提示用户。

### 其他安装安全性改进

- 更新前校验压缩包中的 Mod Id，发现与目标 Mod 不一致时直接拒绝安装。
- 为安装、更新、卸载和启停操作增加全局互斥，避免多个操作同时修改 Mods 目录。
- 针对重复文件夹、文件占用、异常 Mod Id 等情况，增加相应的回滚或拒绝处理机制。

## 游戏目录路径处理改进

部分 Steam 注册表中的安装路径可能采用正斜杠（`/`），此前在拼接路径时可能产生正反斜杠混用的情况，导致 Windows 无法正确识别路径，甚至在打开文件夹时错误跳转到「文档」。

现在：

- 自动检测、设置页面手动输入以及旧配置文件读取，都会统一转换为 Windows 标准反斜杠路径。
- 修复混合路径分隔符导致的游戏目录和 Mod 文件夹打开异常。
- 这类混合分隔符路径不会再出现在日志和诊断包的游戏目录中。

## 加载器与内核安全性改进

- 部署加载器前，先检查内核压缩包完整性，避免出现新 UMM 文件已复制、却发现注入组件缺失的情况。
- 检测到 BepInEx 等其他加载器时，会提前备份其 `winhttp.dll` 和 `doorstop_config.ini`，卸载 UMM 加载器后自动恢复。
- 部署时记录 `winhttp.dll` 的哈希值，使从资源站下载或通过本地文件导入的内核也能正确识别归属。
- 内核校验增加 `UnityModManager.dll` 程序集名称检查，不再仅依赖文件名判断。
- Aurora 自动更新和 UMM 内核获取改为使用固定的 ADOFAI Tools 条目（slug），不再通过名称模糊匹配，避免自定义站点错误提供 Aurora 更新或内核。

## 更新与下载安全性改进

- 自动更新和内核下载仅接受 HTTP / HTTPS 地址，本地文件仅用于用户主动选择的 ZIP 文件及开发测试包。
- 发版时会生成 `SHA256SUMS.txt`，客户端下载安装包后会校验 SHA256，校验不一致时中止更新。
- 如果因网络问题无法连接 GitHub 或获取校验文件，仍允许继续更新，但会明确提示本次更新未进行哈希校验。
- 绿色版更新脚本增加 `robocopy` 退出码检查，复制失败时不再启动文件混杂的新旧版本程序，而是保留新版本并提示用户手动覆盖。

> 从本版本开始，GitHub Release 除安装版和绿色版 ZIP 外，还会附带 `SHA256SUMS.txt` 校验文件。

## 配置、诊断与链接处理改进

- `Params.xml` 损坏时，会先备份为 `.broken` 文件，不再直接覆盖；配置写入也改为临时文件写入完成后再重命名替换。
- 收藏、安装映射和更新源等文件损坏时，同样会先进行备份。
- 诊断包文件名精确到秒，避免同一分钟内多次导出发生文件名冲突。
- Mod 来源接口的缓存键增加站点地址，避免默认站点与自定义站点之间出现缓存数据串用。
- Markdown 内容及页面中的外部链接增加协议限制，仅允许 HTTP、HTTPS 和 Mailto，避免 `file:`、`search-ms:` 等协议被直接交给系统打开。

## 关于 v0.1.12.2 更新日志的说明更正

此前 v0.1.12.2 更新日志将「打开文件夹跳转到文档」的问题归因于文件夹不存在，但实际主要原因是**路径分隔符混用**。

v0.1.12.2 仅处理了文件夹确实不存在的情况，而 v0.1.13 则从游戏目录检测和路径保存的源头进行了修正。

## 开发与测试

本次还补充了自动化测试和持续集成流程：

- 新增 `tests/Aurora.Tests`，覆盖安装、更新、卸载、中断恢复、路径处理、并发操作、配置损坏及加载器备份等场景，共计 43 项回归测试。
- 新增 Windows GitHub Actions 工作流，自动执行构建、测试及 LoaderSmokeTest。
- 后续代码改动可以通过 CI 自动验证，减少对本地手动测试的依赖。

## 升级方式

**建议所有用户更新至 v0.1.13。**

使用 v0.1.6 或更高版本的用户，可以直接在软件内点击「立即更新」。

也可以退出软件后手动升级：

| 版本 | 操作 |
| --- | --- |
| 安装版 | 运行 `Aurora-Setup-0.1.13.exe`，覆盖安装即可 |
| 绿色版 | 下载 ZIP 压缩包，解压后覆盖原有程序目录 |

> v0.1.5 及更早版本自带的自动更新功能存在问题，请手动下载安装包覆盖安装，或解压 ZIP 覆盖原程序目录。

升级不会影响原有设置、收藏和日志。**建议在升级前备份游戏目录中的 `Mods` 文件夹。**
