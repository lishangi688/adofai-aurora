# Aurora v0.1.12.1

本次为小补丁更新，主要修复安装、更新或卸载 Mod 等操作期间，误关闭窗口可能导致文件写入中断的问题，进一步提高操作安全性。

## 关键操作期间关闭窗口增加确认提示

此前，在安装、更新或卸载 Mod 等涉及文件写入的操作过程中，如果误关闭 Aurora 窗口，可能导致当前操作被中断，使游戏目录中留下不完整的 Mod 或加载器文件。

现在，当以下操作正在进行时，关闭窗口会先弹出确认提示：

- 安装 / 更新 Mod
- 卸载 Mod
- 切换 Mod 的启用状态
- 安装 / 修复 / 卸载 UMM 加载器
- 部署内核

确认提示会说明当前正在执行的操作，并默认选择「否」：

- **选择「否」：** 取消关闭窗口，当前操作继续执行。
- **选择「是」：** 仍然退出 Aurora，但当前操作可能被中断。

首次使用向导中的内核安装也加入了相同的保护机制。

**特殊情况：**

本地 ZIP 安装采用同步执行方式，安装期间窗口可能会短暂无响应。此时关闭操作会等待安装结束后再处理，不会出现安装过程中窗口被直接关闭的情况。

## 升级方式

**建议所有用户更新。**

使用 v0.1.6 或更高版本的用户，可以直接在软件内点击「立即更新」。

也可以退出软件后手动升级：

| 版本 | 操作 |
|---|---|
| 安装版 | 运行 `Aurora-Setup-0.1.12.1.exe`，覆盖安装 |
| 绿色版 | 将 ZIP 压缩包解压并覆盖到原来的程序目录 |

> v0.1.5 及更早版本自带的自动更新功能存在问题，请手动下载安装包覆盖安装，或解压 ZIP 覆盖原程序目录。

升级不会影响原有设置、收藏和日志。建议升级前备份游戏目录中的 `Mods` 文件夹。
